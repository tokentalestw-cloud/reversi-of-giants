# 科學巨人黑白棋 · Reversi of Giants

可線上對戰的 3D 黑白棋。召喚 9 位歷代科學家，每局 3 次特殊技能，能力與其研究領域結合。

## 本機執行
```bash
python server.py        # 預設 http://localhost:8765
```
Windows 可直接雙擊 `start.bat`。只需 Python 3.8+，無任何第三方套件。

## 部署到 Render
1. 將此 repo 推上 GitHub
2. Render → **New → Blueprint** → 選擇此 repo（會讀取 `render.yaml`）
3. 部署完成後把 `https://<服務名稱>.onrender.com` 分享給朋友即可連線對戰

> 免費方案閒置 15 分鐘會休眠，首次喚醒約需 30–60 秒。

## 科學家
| 科學家 | 技能 | 效果 |
|---|---|---|
| 牛頓 | 萬有引力 | 落子後拉翻上下左右緊鄰敵子 |
| 愛因斯坦 | 時間膨脹 | 落子後再行動一回合 |
| 居禮夫人 | 放射性衰變 | 周圍 2 格隨機最多 3 枚敵子翻轉 |
| 特斯拉 | 特斯拉線圈 | 連鎖閃電最多翻 4 子 |
| 法拉第 | 法拉第籠 | 3×3 己方棋子護盾 2 回合 |
| 霍金 | 黑洞 | 任意空格變永久黑洞並吞噬周圍敵子 |
| 圖靈 | 密碼破譯 | 敵子倒戈並由此夾擊 |
| 薛丁格 | 量子疊加 | 50% 大量翻轉 / 50% 變成對手棋子 |
| 達爾文 | 天擇 | 被己方包圍（≥5）的敵子同化 |

## 技術
- 前端：Three.js（PBR 材質、Bloom 後製、GPU 粒子）、Web Audio 合成音效
- 後端：Python asyncio 自製 HTTP + WebSocket 伺服器（房間配對與動作轉發）
- 同步：雙方以相同亂數種子執行決定性規則引擎，只傳送玩家動作
